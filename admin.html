🔧 Admin — QR Codes

Génère et imprime les QR codes à placer dans les bureaux

⚙️ Configuration

Remplacez par l'URL de votre site GitHub Pages.
Format : https://USERNAME.github.io/NOM-DU-REPO/
Instructions :
1. Entrez l'URL de votre GitHub Pages ci-dessus
2. Cliquez "Générer les QR codes"
3. Imprimez-les en cliquant "Imprimer / PDF"
4. Découpez et placez chaque QR code dans la zone correspondante des bureaux
5. Les stagiaires scannent avec leur téléphone !
